# ScholarPath dark workspace redesign

## Goal
Apply the latest supplied dark Scholarship Intelligence Workspace design to the existing app, preserving its current pages and behavior.

## Work
- Replace the warm/light draft direction with semantic charcoal, deep teal, lime, text, and border tokens; load Space Grotesk for headings and retain Inter for interface copy.
- Restyle the existing compact navigation, header, controls, forms, status markers, scholarship dossiers, eligibility ledger, and deadline timeline consistently.
- Keep the existing dashboard, discovery, detail, eligibility, saved, profile, and application functionality and the prototype's honesty about sample records.
- Validate route/search behavior, responsiveness, and build/test signals.

## Technical notes
- Keep existing TanStack Start routes, feature modules, state and local persistence; no new backend or dependencies.
- Use semantic tokens and existing design-system buttons; maintain keyboard focus, contrast, and reduced-motion support.
